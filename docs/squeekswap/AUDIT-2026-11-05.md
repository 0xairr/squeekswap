# Relaunch review, 2026-11-05

Scope: Squeekchain's relaunch, SqueekSwap's move to the new contracts, the registry change, domain verification and live checks. The SqueekSwap V2 contract was not changed.

## What happened

1. **Squeekchain replaced every contract on 2026-11-03** (installation `sepolia-core-sepolia-20261103`), including the Genesis collection. `/v1/economy/state` dropped its `identities` field; contract addresses moved to `deployment.components`. The web app's contract-graph check therefore failed for every wallet, and holdings showed "Could not load Genesis NFTs".
2. **`www` stopped resolving during domain verification.** `www` had no record of its own; it resolved through Vercel's `*` wildcard. Adding the `_squeekchain.www` TXT record made `www` an existing (empty) name, and DNS wildcards never answer for existing names, so public resolvers returned no address. Fixed with an explicit `www` ALIAS to `cname.vercel-dns-017.com`.
3. **Prerendered pages answer byte-range requests with 206.** The home page is now rendered per request, so any checker gets a full 200 with the `squeekchain-project` tag.

## New Genesis contract

- Source is **not verified** on Etherscan, Sourcify or Blockscout. Review is from bytecode and behaviour.
- Not a proxy (EIP-1967 implementation slot empty); 9,788-byte runtime; supports ERC-165 ERC-721.
- Functions decoded from the bytecode: standard ERC-721, ERC-2981 `royaltyInfo` (view only; SqueekSwap pays no royalties), `level`, `merge(uint256,uint256)`, mint controls (`premint`, `pauseMint`, `unpauseMint`), reveal (`announceReveal`, `revealState`) and launch configuration. No transfer lock, blocklist, transfer fee or transfer hook was found. `paused()` is the mint pause.
- `tokenURI` is base64 JSON with an inline base64 SVG (55–64 KB, about 1,120 `<use>` elements), already revealed. The existing renderer handles it.
- IDs 1–9,999 are minted; until claims open they sit with Squeekchain's dispenser and signer.
- Impact on SqueekSwap: `merge` can burn an offered or wanted token, which makes `fill` revert (no loss), or raise a level, which the offer page already warns about.

## Changes

- Registry: enabled the relaunched Genesis; disabled the retired first Genesis `0xCB98…B70F`, which reports the same `Squeek`/`SQUEEK` name. Only the relaunched Genesis is supported.
- Web: new canonical addresses; the graph check reads `deployment.components`; new Zoomies genesis timestamp; artwork version `w2` so browsers drop the old collection's thumbnails; home page rendered per request; Squeekchain project meta tag.
- Tests: three unit tests for the graph check (new shape accepted, wrong collection refused, missing addresses refused); fork tests rewritten for the relaunched Genesis.

## Remaining risks

- The relaunched Genesis source is unverified. Re-review if Squeekchain publishes it.
- No real two-wallet swap is possible until Squeekchain opens Genesis claims; `offerCount` is still 0.
- A future relaunch would fail closed: holdings show an error until the build is updated (see the runbook in `DEPLOYMENT.md`).
- The `_squeekchain.www` TXT record and the explicit `www` record must both stay.
